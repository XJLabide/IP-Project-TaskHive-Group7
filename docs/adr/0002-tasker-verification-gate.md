# Require stronger Tasker verification before assignment

Participants must complete a basic profile (name, verified email/phone, and 18+ attestation) before posting or applying. Taskers may browse and submit bids or fixed-price requests before completing stronger identity checks, but cannot be assigned until a verification provider confirms their identity. A rejected Tasker may browse only and can submit one appeal for Admin review; existing bids/requests are withdrawn and Posters are notified. If the appeal succeeds, the Tasker must resubmit. Admin also reviews provider exceptions. The provider retains identity documents; TaskHive stores only verification status and a provider reference, limiting sensitive data held by the marketplace.
