# Require stronger Tasker verification before assignment

Participants must complete a basic profile (name, verified email, and 18+ attestation) before posting or applying; phone verification is not required because TaskHive does not send SMS. Taskers may browse and submit bids or fixed-price requests before completing stronger identity checks, but cannot be assigned until verified. A rejected Tasker may browse only and can submit one appeal for Admin review; existing bids/requests are withdrawn and Posters are notified. If the appeal succeeds, the Tasker must resubmit. This original decision expected an external verification provider to retain identity documents; Admin review and TaskHive-controlled private ID storage supersede that custody decision in ADR-0013.
