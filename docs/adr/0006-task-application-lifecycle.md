# Preserve applications across a payment retry

After Poster approval, reserve the task and selected Tasker for a 24-hour payment retry window; keep other bids or requests pending and block new applications. If payment is not completed before expiry, clear the selection, reopen the task, and retain existing applications. A Poster’s material edits to an open task invalidate its applications and notify affected Taskers; Taskers may withdraw until assignment.
