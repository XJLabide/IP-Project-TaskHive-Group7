# Admin-reviewed Tasker ID submissions

Taskers submit one consented photo of a valid, unexpired government-issued photo ID. TaskHive stores the image as an authenticated private Cloudinary asset; only authorized Admins can retrieve it through the application. Admin approval unlocks assignment, rejection preserves the existing one-appeal process, and the image is deleted after the decision. The database retains consent time, verification state, and an auditable Admin decision, but not the image.
