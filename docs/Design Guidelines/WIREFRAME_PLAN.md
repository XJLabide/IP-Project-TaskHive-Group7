## Wireframe Style
- Use white, gray, and black only.
- Use low-fidelity blocks, boxes, labels, and simple form fields.
- Do not focus on branding colors yet.
- Keep layouts practical and readable.
- Use desktop frames first.
- Add mobile frames only for the most important pages if time allows.
