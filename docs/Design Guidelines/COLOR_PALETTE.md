# TaskHive Color Palette

This palette records the visual direction from the TaskHive landing-page reference image. The values are approximate estimates from the image, not sampled source tokens. This document is a design reference only; it does not change the app's current colors.

## Palette

| Role | Color | Suggested use |
| --- | --- | --- |
| White | `#FFFFFF` | Main page background and clean surfaces |
| Pale mint | `#EFF8F6` | Alternate section backgrounds and soft supporting surfaces |
| Deep teal | `#087C78` | Brand mark, trust indicators, selected icon accents, and emphasis |
| Dark navy | `#111E29` | Headlines and primary body text |
| Bright orange | `#FFA900` | Primary actions, ratings, and small highlights |
| Light gray | `#E3E8E8` | Dividers, borders, and secondary interface details |

## Usage

- Keep most page areas white or pale mint so the layout feels open and calm.
- Use dark navy for important text to preserve clear contrast on light surfaces.
- Use teal for community and trust cues; reserve orange for the most important action or highlight in a section.
- Use light gray for separation and low-priority details rather than important text.
- Treat these values as a starting point. Check text and control contrast in the rendered interface before adopting them as production design tokens.
